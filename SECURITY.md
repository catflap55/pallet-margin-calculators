# Security

These files are calculator math and browser widgets. When you upload a CSV in the widgets, that file stays in **your browser**. The local preview only listens on this computer (`127.0.0.1` / `localhost`). It is not a public website.

Please **do not** open issues or pull requests that include:

- Passwords, API keys, or `.env` files
- WordPress, hosting, or email logins
- Session cookies or admin screenshots that show secrets

Report a security problem with the live site using the contact page on [palletmargincalculator.site](https://palletmargincalculator.site/contact/).
