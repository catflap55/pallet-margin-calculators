This folder is for Linux only.

1. Install Python 3 (see README.md, Linux section)
2. Right-click Start.sh → Run as a program / Run in Terminal

If nothing happens, in Terminal:
  cd into this Linux folder, then:
  bash Start.sh

Leave that window open while you use the calculators.
In the browser try http://localhost:43141/preview.html and
http://127.0.0.1:43141/preview.html (they are the same tools).
If one fails, use the other.

Stop: bash Stop.sh  (or press Ctrl+C in the Start window)

You do not need Node.js to use the calculators.
More detail: ../README.md  (Linux section)
